Bring the thumb and index finger of each hand up in front of the camera, like you're framing a photo. The four fingertips form a window — everything inside it is run live through the real AnimeGANv3 neural network (in a background Web Worker, so the page never freezes) and rendered as actual anime-style art; everything outside stays the real camera feed. Pick a style from the dropdown once the camera's running.

512×512
Runs fully in your browser — no video leaves your machine. Hand tracking (MediaPipe Hands) stays on the main thread; the AnimeGANv3 ONNX model runs inside a dedicated Web Worker via onnxruntime-web (WASM, multi-threaded when the browser allows it), so a slow inference pass can no longer freeze the camera feed, hand tracking, or the UI — and the worker fires the next pass the instant the previous one lands, with no idle gap in between. Switch styles any time with the dropdown once the camera's running; each style's weights are cached in the worker after their first download, so switching back to one you've already used is instant, and the window keeps rendering with the old style while a new one loads in the background. Note: v3 also has USA/Disney/Arcane/Kpop/Trump/JP_face demo styles, but those only exist bundled inside the official Gradio demo's own inference code with no standalone .onnx file to download — so they aren't in the list rather than pointing at a link that would 404. The window's outline tracks your hands every single frame; for the art inside it, a cheap instant preview renders every frame so it's never static, real AnimeGAN results crossfade in smoothly instead of popping, and a faint live shimmer keeps the window visibly moving between GAN passes. If the model or camera fails to load in this sandbox, download the file and open it from a local server, e.g. python3 -m http.server.
