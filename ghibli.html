Bring the thumb and index finger of each hand up in front of the camera, like you're framing a photo. The four fingertips form a window — everything inside it is run live through the real AnimeGANv2 neural network (in a background Web Worker, so the page never freezes) and rendered as actual anime-style art; everything outside stays the real camera feed.

512×512 (fixed)
Runs fully in your browser — no video leaves your machine. Hand tracking (MediaPipe Hands) stays on the main thread; the AnimeGANv2 (face_paint_v2) ONNX model runs inside a dedicated Web Worker via onnxruntime-web (WASM), so a slow inference pass can no longer freeze the camera feed, hand tracking, or the UI. Honest caveat: this is a real generative model, not a cheap filter — each stylized refresh can take real time on a CPU (often multiple seconds per pass). The window's outline still tracks your hands every frame in real time; the art inside it updates only as fast as the worker finishes each pass, and the previous result stays visible while the next one renders. If the model or camera fails to load in this sandbox, download the file and open it from a local server, e.g. python3 -m http.server.
